# Liquidation Shield Dashboard

Next.js 14 App Router control dashboard for the Automated Liquidation Shield.

## How to run
1. Execute the scenario script from `project/backend/`:
   ```bash
   cd project/backend
   node --experimental-strip-types scripts/scenarios/01-save.ts
   ```
2. Start the dashboard from `project/frontend/dashboard/`:
   ```bash
   pnpm dev
   ```
3. Open [http://localhost:3000](http://localhost:3000)
